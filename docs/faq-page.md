# Συχνές ερωτήσεις

Δημιουργήστε σελίδα και επιλέξτε πρότυπο **Συχνές ερωτήσεις**, αποθηκεύστε και ανανεώστε τον editor για τα πεδία ACF Free. Προσθέστε τη δημοσιευμένη σελίδα στο μενού του WordPress.

Υπάρχουν 8 θέσεις ερωτήσεων/απαντήσεων. Κενή ερώτηση ή απάντηση κρύβει τη θέση. Τα αρχικά κείμενα είναι ενδεικτικά και χρειάζονται έγκριση της επαγγελματία πριν τη δημοσίευση. Η φωτογραφία, το πλαίσιο επικοινωνίας, η εισαγωγή και το τελικό CTA αλλάζουν από την ίδια σελίδα. Η αρχική φωτογραφία επαναχρησιμοποιεί την εικόνα βιβλίου του theme.

Η πρώτη ορατή απάντηση είναι ανοικτή. Με JavaScript ανοίγει μία κάθε φορά. Χωρίς JavaScript λειτουργούν ανεξάρτητα τα native details/summary με πληκτρολόγιο. Τα στοιχεία τηλεφώνου παραμένουν κοινά με την αρχική. Οι σύνδεσμοι εντοπίζουν τη σελίδα Επικοινωνίας, με εναλλακτική το #contact της αρχικής.

Αρχεία: inc/faq.php, page-templates/faq.php, style.css, assets/js/main.js. Δεν απαιτείται ACF Pro.
