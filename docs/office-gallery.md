# Φωτογραφίες γραφείου

Μετά το Update from Remote και Deploy HEAD Commit:

1. Ανοίξτε Σελίδες → Αρχική.
2. Στην ομάδα «Ο χώρος μου — Συλλογή φωτογραφιών» επιλέξτε έως έξι εικόνες στα πεδία Φωτογραφία 1–6.
3. Βάλτε τη σειρά που θέλετε· κενά και διπλές εικόνες παραλείπονται. Αποθηκεύστε τη σελίδα.
4. Στα Πολυμέσα ορίστε εναλλακτικό κείμενο και προαιρετική λεζάντα για κάθε φωτογραφία.

Το κουμπί «Δείτε τον χώρο» ανοίγει τη συλλογή πάνω από τη σελίδα. Διαθέτει προηγούμενη/επόμενη, μετρητή, λεζάντα, κλείσιμο, Escape και αριστερό/δεξί βέλος πληκτρολογίου. Το native dialog κρατά την εστίαση μέσα στη συλλογή και επιστρέφει στο κουμπί κατά το κλείσιμο. Με μία εικόνα κρύβονται τα βελάκια.

Χωρίς επιπλέον επιλογές χρησιμοποιείται μόνο η κύρια ανεβασμένη φωτογραφία της ενότητας «Ο χώρος μου». Αν δεν υπάρχει καμία πραγματική εικόνα, παραμένει το παλιό κουμπί επικοινωνίας/παρουσίασης. Τα placeholders δεν μπαίνουν στη συλλογή. Όταν υπάρχουν φωτογραφίες, το προηγούμενο πεδίο «Σύνδεσμος παρουσίασης» δεν καθορίζει τον προορισμό: ανοίγει η συλλογή.

Χωρίς JavaScript εμφανίζεται αναπτυσσόμενη συλλογή με συνδέσμους προς τις φωτογραφίες. Δεν απαιτείται πρόσθετο, ACF Pro, gallery/repeater field ή βιβλιοθήκη lightbox. Το CSS βρίσκεται στο style.css και το JavaScript στο assets/js/main.js.

Έλεγχοι πριν την παράδοση στο live: επιλογή πολλών εικόνων, άνοιγμα/εναλλαγή/κλείσιμο, Escape, επιστροφή εστίασης, κινητό σε κάθετο/οριζόντιο προσανατολισμό και απενεργοποιημένο JavaScript.
