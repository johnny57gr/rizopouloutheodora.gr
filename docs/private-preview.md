# Ιδιωτική προεπισκόπηση

1. cPanel: Update from Remote, έπειτα Deploy HEAD Commit.
2. Εμφάνιση → Προσαρμογή → Υπό κατασκευή: ενεργοποίηση και Δημοσίευση.
3. Εμφάνιση → Ιδιωτική προεπισκόπηση → Ενεργοποίηση / Δημιουργία συνδέσμου.
4. Αντιγράψτε τον σύνδεσμο και στείλτε τον ιδιωτικά. Η πρόσκληση και η πρόσβαση λήγουν 7 ημέρες μετά τη δημιουργία, όχι 7 ημέρες μετά από κάθε άνοιγμα.
5. Ανανέωση συνδέσμου ακυρώνει τον παλιό σύνδεσμο και όλα τα ήδη εκδοθέντα cookies. Η Απενεργοποίηση επίσης ανακαλεί κάθε πρόσβαση.

Ο παραλήπτης δεν συνδέεται στο WordPress και δεν αποκτά δικαιώματα διαχείρισης. Ο σύνδεσμος ανταλλάσσεται με υπογεγραμμένο HttpOnly / SameSite=Lax cookie (Secure σε HTTPS). Ακολουθεί ανακατεύθυνση στην αρχική χωρίς το μυστικό στο URL. Ο σύνδεσμος είναι bearer secret: όποιος τον έχει αποκτά την ίδια προεπισκόπηση. Μη δημοσιεύετε τον σύνδεσμο στο Git ή σε screenshots.

## Έλεγχος στο hosting

Αδειάστε και απενεργοποιήστε τυχόν full-page cache/CDN όσο λειτουργεί η προεπισκόπηση με Under Construction. Το theme στέλνει private/no-store, noindex και DONOTCACHEPAGE, αλλά δεν μπορεί να ελέγξει cache που εξυπηρετεί πριν εκτελεστεί το WordPress. Δοκιμάστε σε δύο ανεξάρτητα ιδιωτικά παράθυρα/browsers: ένας χωρίς πρόσκληση βλέπει Υπό κατασκευή, ο άλλος με πρόσκληση βλέπει τις σελίδες. Μετά την ανάκληση, νέα φόρτωση στον δεύτερο πρέπει να δείχνει Υπό κατασκευή. Περιεχόμενο ήδη ανοικτό σε μια καρτέλα δεν διαγράφεται αναδρομικά.

Αυτό παρακάμπτει μόνο την υπάρχουσα οθόνη του frontend. Δεν είναι προστασία εμπιστευτικών αρχείων, uploads, REST API ή άλλων endpoints. Αν κλείσει το Under Construction, το site γίνεται δημόσιο όπως πριν. Η φόρμα επικοινωνίας παραμένει πραγματική και μπορεί να στείλει email.

Υλοποίηση: inc/private-preview.php, με manage_options και nonce για κάθε διαχειριστική αλλαγή. Η πρόσκληση αποθηκεύεται μόνο στη βάση. Καμία εξάρτηση από plugin ή ACF.

Αναφορά WordPress: https://developer.wordpress.org/reference/functions/wp_safe_redirect/ και https://developer.wordpress.org/reference/functions/nocache_headers/.
